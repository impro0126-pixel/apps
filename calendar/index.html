중계기(Worker)

구글·애플·네이버 서버는 웹페이지가 직접 읽어 가지 못하게 막혀 있어서, 내 Cloudflare Worker 가 대신 받아 줍니다. 무료입니다.

Worker 만드는 법 (5분)
  1. Cloudflare 가입 → Workers & Pages → 만들기 → Worker 만들기 → 배포
  2. 코드 편집 → worker.js 내용을 통째로 붙여넣고 배포
  3. 설정 → 변수 및 비밀 → ACCESS_KEY 를 '비밀'로 추가 (아무 긴 문자열)
  4. Worker 주소와 그 키를 위 칸에 넣기
