어떤 앱인가요

여기저기 흩어진 일정을 한 달력에 모아 봅니다. 날짜마다 음력이 붙고, 공휴일과 대체공휴일은 빨갛게 보입니다.

  • 기기에 넣어 둔 계정(구글·iCloud·회사 등)의 달력을 읽고, 고친 것을 그 달력에 저장합니다
  • 네이버 캘린더는 앱 안에서 직접 연결합니다(네이버 앱 비밀번호)
  • 맥에서는 달력이 바탕화면에 깔려 늘 보입니다
  • 「다음 주 화요일 3시 치과」처럼 적으면 날짜와 시간을 채워 줍니다. 알아듣는 일은 기기 안에서 합니다
  • 음력 생일·제사는 「음력으로 해마다」 한 번이면 해마다 들어갑니다
  • 연휴 사이에 연차를 하루 쓰면 며칠 쉬는지 알려 줍니다
  • 위젯, 단축어·시리로도 씁니다
  • 가입도 로그인도 광고도 없습니다
도움이 필요하시면 impro0126@gmail.com 으로 메일 주세요. 어떤 기기에서 어느 달력을 보려다 그랬는지 알려주시면 찾기가 빠릅니다.

자주 묻는 것

구글 달력이 안 보여요

모아볼게요는 기기에 넣어 둔 계정을 읽습니다. 아이폰은 설정 → 앱 → 캘린더 → 캘린더 계정에서, 맥은 시스템 설정 → 인터넷 계정에서 구글 계정을 더하고 「캘린더」를 켜 주세요. 처음 켤 때 달력 보기를 허락하지 않으셨다면 설정 → 개인정보 보호 및 보안 → 캘린더에서 모아볼게요를 「전체 접근」으로 바꿔 주세요.

네이버 캘린더는 어떻게 연결하나요

맥은 메뉴 막대의 달력 그림 → 「네이버 연결…」(또는 꾸미기 창), 아이폰은 달력 위 ⋯ 메뉴 → 「네이버 연결」에서 네이버 아이디와 네이버 앱 비밀번호를 넣습니다. 앱 비밀번호는 네이버 → 내 정보 → 보안설정 → 2단계 인증 「관리」 → 「애플리케이션 비밀번호 관리」에서 만듭니다. 평소 로그인 비밀번호가 아닙니다. 넣은 비밀번호는 기기의 키체인에만 저장됩니다.

같은 네이버 일정이 두 번 보여요

네이버를 기기 설정에도 넣고 앱에서도 연결하면 같은 일정이 두 곳에서 옵니다. 앱은 같은 일정을 하나로 합치지만, 기기 설정 쪽 네이버 캘린더를 꺼 두시면 더 깔끔합니다.

맥 바탕화면 달력을 옮기고 싶어요

메뉴 막대의 달력 그림 → 「달력 창 옮기기·크기 바꾸기」를 누르면 보통 창이 됩니다. 끌어서 옮기고 모서리로 크기를 바꾼 뒤 「다 됐어요 — 바탕화면에 깔기」를 누르세요. 배경 진하기와 글자 크기는 「꾸미기」에서 바꿉니다.

음력 반복 일정은 어떻게 들어가나요

기기 달력은 양력 반복만 알아서, 모아볼게요가 앞으로 10년 치를 하루짜리 일정으로 넣고 해가 지나면 저절로 채웁니다. 제목을 고치면 묶음 전체가 바뀌고, 지울 때는 「이 해만」과 「해마다 모두」 가운데 고릅니다.

잘못 지웠어요

반복이 아닌 일정은 지운 뒤 30일 동안 단축어 「모아볼게요 지운 일정 되살리기」로 되살릴 수 있습니다.

다음 해 공휴일은요

공휴일은 앱 안에 들어 있습니다. 정부가 다음 해 공휴일을 정하면 앱 업데이트로 넣습니다. 아직 없는 해를 보면 달력 위에 그렇다고 알려 드립니다.

일정이 어디로 가나요

일정은 원래 있던 달력(기기 계정, 네이버)에만 저장됩니다. 앱을 만든 사람의 서버로 보내지지 않습니다. 자세한 것은 개인정보처리방침을 봐 주세요.
