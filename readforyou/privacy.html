개인정보처리방침

최종 수정: 2026년 8월 14일

뭐든지 읽어드릴게요는 사용자의 개인정보를 수집하지 않습니다. 계정도 없고, 앱을 만든 사람이 운영하는 서버도 없습니다. 넣으신 문서와 설정은 사용하시는 기기에만 남습니다.

1. 수집하지 않는 것

이 앱은 다음을 일절 수집하지 않습니다.

  • 이름·이메일·전화번호 등 신원 정보 (회원가입 자체가 없습니다)
  • 위치 정보
  • 연락처, 사진 보관함 전체에 대한 접근
  • 사용 기록·분석 정보 (분석 도구나 광고 모듈이 들어 있지 않습니다)
  • 기기 식별자

2. 기기 안에만 남는 것

아래 자료는 사용하시는 기기에만 저장되며 외부로 전송되지 않습니다.

무엇어디에
넣으신 문서의 글, 제목, 그룹, 듣던 위치앱의 문서 폴더
원본 PDF·사진 (다시 추출에 씁니다)앱의 문서 폴더
받아 둔 음성 파일앱의 지원 파일 폴더
읽는 법·안 읽을 줄·배속 같은 설정앱 설정 저장소
OpenAI API 키기기 보안 저장소(키체인)

앱을 삭제하면 위 자료는 기기에서 함께 지워집니다. 앱 안에서 지우려면 각 글을 삭제하거나, 설정에서 저장된 음성·읽는 법·안 읽을 줄을 지우시면 됩니다.

3. 외부로 나가는 경우 — 사용자가 고를 때만

이 앱에는 개발자가 운영하는 서버가 없습니다. 사용자의 자료가 개발자에게 전달되는 경로 자체가 존재하지 않습니다.

다만 사용자가 본인의 OpenAI API 키를 넣고 OpenAI 기능을 직접 고른 경우, 아래 자료가 사용자 본인의 OpenAI 계정으로 OpenAI에 직접 전송됩니다.

기능무엇이 나가나언제
OpenAI 음성으로 읽기읽을 문장의 글음성 엔진을 OpenAI로 고른 경우
OpenAI로 글자 뽑기문서·사진의 이미지그 방식을 고르거나 「다시 추출」을 누른 경우
  • 이 통신은 앱 개발자를 거치지 않습니다. 개발자는 전송 내용을 볼 수 없습니다.
  • 요금은 사용자의 OpenAI 계정에 직접 청구됩니다.
  • 전송된 자료의 처리는 OpenAI의 개인정보처리방침을 따릅니다.
  • 기본 설정은 기기 안에서 무료로 처리하는 쪽입니다. 위 기능은 사용자가 설정에서 켜야 동작합니다.
  • 계약서·의료 기록처럼 민감한 문서는 OpenAI 기능을 끄고 기기 안 처리만 쓰시기를 권합니다.

4. 기기 권한

권한왜 필요한가
사진사용자가 직접 고른 사진을 읽어 오기 위해서입니다. 보관함 전체를 훑지 않습니다.
파일사용자가 직접 고르거나 끌어다 놓은 파일을 읽어 오기 위해서입니다.

두 권한 모두 사용자가 그 자리에서 고른 항목에만 적용됩니다.

5. 제3자 제공

개발자는 어떤 자료도 제3자에게 제공하거나 판매하지 않습니다. 수집하는 자료 자체가 없기 때문입니다. 앱에는 광고·분석·추적 도구가 들어 있지 않습니다.

6. 아동의 개인정보

이 앱은 아동을 대상으로 하지 않으며, 나이와 무관하게 어떤 개인정보도 수집하지 않습니다.
